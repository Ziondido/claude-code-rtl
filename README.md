# Claude Code RTL

Adds automatic RTL (Right-to-Left) support for Hebrew, Arabic and Persian to [Claude Code](https://marketplace.visualstudio.com/items?itemName=anthropic.claude-code) in VS Code, Cursor and Antigravity.

## How it works

- Detects RTL text (Hebrew/Arabic/Persian) per chat bubble automatically
- Applies correct direction and alignment — no manual configuration
- Toggle button (⇄) in the Claude Code header to enable/disable on the fly
- State remembered across sessions

## Requirements

- [Claude Code extension](https://marketplace.visualstudio.com/items?itemName=anthropic.claude-code) must be installed

## Install

1. Install this extension
2. A notification will ask to reload — click **Reload**
3. The ⇄ button appears in Claude Code's header

## Usage

Click **⇄** in the Claude Code chat header to toggle RTL on/off.

Blue = RTL active. Grey = inactive.

## Languages supported

Hebrew · Arabic · Persian (Farsi)

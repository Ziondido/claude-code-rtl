why is my useEffect running twice in dev mode?
Claude
React 18 intentionally runs effects twice in development with Strict Mode to help catch bugs. It mounts → unmounts → remounts to simulate future React behavior.

If your effect has side effects that shouldn't run twice, add a cleanup function:
tsx
useEffect(() => {
  fetchData();
  return () => controller.abort();
}, []);
